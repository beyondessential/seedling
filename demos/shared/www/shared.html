A shared page

This page and its stylesheet live once in the repository, in demos/shared/www/. The bundle-tour and bundle-share demos each name that folder in the [include] table of their seedling.toml, so seedling-ctl copies it into each bundle when it reads the demo's folder. The host only ever sees a self-contained bundle, and both demos serve these same bytes.

The helper that builds the web server, demos/shared/static-site.rhai, is shared the same way, as the first of each demo's script files.
