A page from the pages folder

This page is pages/guide.html in the bundle. The script writes the whole pages folder into the root of the site volume with write_dir("/", app.dir("pages")), so it is served at /guide.html, byte for byte as the bundle holds it.

Its neighbour pages/draft.html is in the repository but matches the demo's .seedignore, so it never reached the bundle and /draft.html is not found.
